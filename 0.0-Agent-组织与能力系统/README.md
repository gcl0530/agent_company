# 组织与能力系统

## 作用

本系统定义完成软件项目需要哪些角色、能力和人机协作边界，并根据实际交付表现更新能力模型。它不保存具体项目的需求、计划或验收事实。

## 输入与输出

| 输入 | 输出 |
| --- | --- |
| 项目能力缺口、实际交付表现、岗位需求 | 角色卡、能力矩阵、人员/Agent 分工、培养或招聘动作。 |

## MVP 使用方式

项目立项时，按 [角色与能力模板](role_and_capability_template.md) 为项目选择负责人和补足能力缺口。项目复盘后，只更新已被实际结果验证的能力结论。

## 质量门

- 每项关键职责都有一名人类负责人。
- Agent 的权限和升级人已明确，不以“会使用模型”替代能力证明。
- 能力评估要能关联到作品、验证记录或项目结果。
