# 客户与交付系统

## 作用

本系统连接客户/业务事实与内部交付，负责环境、交付包、验收和反馈回流。它不替代产品定义，也不允许在没有证据时宣称软件已交付或客户已验收。

## 最小流程

`客户需求证据 -> 环境与接口澄清 -> 交付准备 -> 部署/操作 -> 验收记录 -> 问题与反馈回流`

正式交付事实写在项目包的 `05_delivery_and_acceptance.md`。Windows 座舱、WSL、Linux 工控机仅在项目实际使用时记录其组件落点、服务、网络/串口权限、日志、升级与回滚。

## 交付质量门

- 版本、依赖、配置、环境和操作步骤可定位。
- 有部署前检查、启动/停止、日志和回滚方式。
- 验收按已确认标准记录实际证据与未覆盖边界。
- 对外承诺、敏感信息处理、发布与验收结论均有明确人类审批。
