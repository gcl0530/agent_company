# 跨模块契约与评测资产模板

> 用于前端、后端、算法、集成/运维之间存在依赖时。它不是完整接口文档，而是保证每个端到端交付切片可以被独立验证的最小合同。详细协议、Schema、样本和测试代码留在项目代码仓库。

- 契约编号与版本：
- 契约 owner（人类）：
- 提供方模块与版本：
- 消费方模块与版本：
- 变更批准人：

## 契约

| 项目 | 内容 |
| --- | --- |
| 业务语义 | 此输入/输出对用户或作业结果意味着什么。 |
| 输入 | 来源、字段/坐标系/单位/时间语义、合法范围、示例位置。 |
| 输出 | 字段、单位、时序、精度/延迟、错误或空值语义、示例位置。 |
| 兼容性 | 版本策略、旧消费者处理、灰度/回退方式。 |
| 安全与权限 | 数据分级、访问主体、脱敏、密钥和禁止外发边界。 |
| 失效处理 | 超时、缺数据、模型不可用、协议不兼容时的降级、告警和升级人。 |
