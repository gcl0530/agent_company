# 产品设计系统

## 作用

本系统把有来源的客户或业务机会转化为可验收的软件问题定义。它负责问题、范围、需求、非目标与验收，不替代项目排期、技术实现或客户最终验收。

## 最小流程

`机会证据 -> 场景与问题 -> 价值与约束 -> 最小范围 -> 验收标准 -> 项目立项`

每个真实项目在项目包的 `02_product_brief.md` 保存正式产品事实。此目录只保存通用方法和模板。

## 产品质量门

- 问题有来源，事实与假设明确区分。
- 用户、使用场景、范围和非目标明确。
- 每条关键需求有可观察或可测量的验收方式。
- 未确认的客户承诺不得作为已定需求进入研发。

模板见 [产品简报模板](templates/product_brief_template.md)。
