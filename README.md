# Agent 公司资料库

## 仓库定位

这是一个面向 Agent 公司建设的资料库，集中沉淀招聘与团队能力建设、机器人研发、产品与项目管理、工具链，以及 AI 协作方法论相关的方案、研究、模板和可视化工具。

当前目录不是一个统一构建的软件工程，也没有全局启动或测试命令。使用内容时，请以具体分区中的源文件、配置和正式材料为准。

## 开始阅读

新接手本仓库时，建议按以下顺序建立上下文：

1. `README.md`：了解资料分区和入口。
2. `AGENTS.md`：了解协作、事实源和交付规则。
3. [产品定义](product_definition.md)：了解服务对象、价值、范围和非目标。
4. [总体设计](overall_design.md)：了解业务系统边界、资产流和演进约束。
5. [实施计划](implementation_plan.md)：了解跨系统建设批次、待办事项和完成判据。
6. 与任务相关的一级目录及其材料。
7. 若任务涉及脚本或可视化，再读取脚本旁的配置、输入数据和生成产物。

不需要一次读完全部资料。先明确任务属于招聘、研发、产品/项目管理、工具链或方法论，再沿该分区深入。

## 正式文档主链

当前正式文档按以下层次承接：

`产品定义 -> 总体设计 -> 跨系统实施计划 -> 各业务系统详细设计/项目级实施计划 -> 验证与复盘记录`

当前已在根目录建立跨系统基线：

- [产品定义](product_definition.md)：定义仓库服务对象、核心价值、范围、非目标和当前 MVP。
- [总体设计](overall_design.md)：定义资料库分层、业务系统边界、事实源与后续文档承接关系。
- [实施计划](implementation_plan.md)：定义资料治理与业务系统建设的批次、任务和验证口径。

详细设计、项目级实施计划及以下文档应随具体业务系统的实际推进，在对应分区内创建。

## 主要使用入口

### 面试与团队能力

- [自动驾驶与机器人领域决规控算法工程师面试系统设计方案](0.0-Agent-面试系统/自动驾驶与机器人领域决规控算法工程师面试系统设计方案.md)：招聘目标、流程、评估维度与题目设计的基础方案。
- `0.0-Agent-面试系统/面试官版-*`：面试官使用的应对材料与题库。
- `0.0-Agent-面试系统/工具可视化_脚本/`：团队能力雷达图工具；`team_members.json` 是数据输入，`radar_chart_visualizer.py` 是生成脚本，`Figure_1.png` 是既有输出示例。

### 研发与技术方案

- `0.1-Agent-研发系统/v1-总体设计方案/`：Nav2 架构、规划、控制器、行为树、参数化与矿山挖掘机适配的研究和方案材料。
- `0.1-Agent-研发系统/v2-详细设计方案-全生命周期文档/`：详细设计与全生命周期文档的预留目录；当前未发现可用材料。
- [机器人控制系统全套技术文档模板](0.1-Agent-研发系统/other-AI/机器人控制系统全套技术文档模板.md)：需求、设计、开发、测试、部署和运维文档的通用模板。

### 工具链与方法论

- `0.5-Agent-工具链/`：工具调研和研发系统相关工具材料；其中 `工具可视化/` 保留与面试系统同结构的雷达图脚本和数据。
- `迭代式E进化/`：用于沉淀 Agent、Codex 和技能建设相关的学习与方法论资料。
- `ref_docs/`：集中管理 AI 编程、协作和软件工程的通用参考材料，不替代项目级需求与技术事实。

## 图表工具

两个雷达图目录分别位于：

- `0.0-Agent-面试系统/工具可视化_脚本/`
- `0.5-Agent-工具链/工具可视化/`

它们均使用 Python、`matplotlib` 和 `numpy`。在对应目录中运行：

```bash
python3 radar_chart_visualizer.py
```

脚本读取同目录的 `team_members.json` 并弹出图表窗口。运行前请确认环境已安装 `matplotlib` 和 `numpy`，并具备图形显示能力。

## 材料维护约定

- `AGENTS.md` 记录长期协作规则；本文件只负责导航和使用说明。
- 脚本与 JSON 配置是可复现图表的事实源；图片只是生成结果。
- Word、PDF、PPTX 和 HTML 材料在改动前应先确认其目标受众和版本关系，避免覆盖原始材料。
- 新形成的正式内容应归入对应业务分区，临时草稿先放入 `Temp/`，定稿后再迁移。
