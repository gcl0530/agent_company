# Agent 创业公司操作系统

## 仓库定位

这是一个用于搭建 Agent 软件创业公司组织架构和流程机制的仓库。公司只做软件，能力范围覆盖前端、后端、自动驾驶算法和机器人自主作业算法；但具体客户、软件形态、功能、算法路线和部署环境由项目决定。Agent 的作用是提升需求分析、研发、测试、交付和复盘能力，不是脱离软件交付另建一套展示系统。

公司主链为：

`客户软件需求 -> 产品定义 -> 项目计划 -> 前端/后端/算法按需协同开发与验证 -> 项目环境交付 -> 客户验收与反馈 -> 复盘与能力沉淀`

当前仓库已经具备招聘、机器人研发、工具链和机制资产；产品、项目、客户与交付系统刚建立入口，尚未完成真实客户软件交付闭环。当前机器人软件资料是通用机制的第一批项目资产。

## 工作原则

- 先确定客户/业务结果，再定义产品、项目、研发和 Agent 工作单元。
- 每个工作单元必须有目标、输入、输出、质量门、权限和升级路径；每个软件项目还必须明确所选前端/后端/算法模块、运行/部署拓扑和验收。Windows 座舱、可选 WSL 和 Linux 工控机是已知环境选项，不是所有项目的固定前提。
- Agent 负责授权范围内的执行与证据整理；商业承诺、安全责任、关键决策和对外发布由人负责。
- 代码、配置、原始数据、测试/交付记录优先于说明文档；通用参考资料不能替代当前项目事实。
- 新结果进入对应业务系统，问题和反馈必须回流到下一轮产品、项目、技术或机制改进。
