# 项目事实与交付档案

每个真实客户或业务项目在此建立一个目录，命名为 `1.1-项目事实与交付档案/<project_id>/`。这里是面向公司管理和跨部门协作的项目概览档案：记录总体方案、概览实施计划、关键决策、交付结论和工程证据索引。

独立项目代码仓库是详细工程事实源，承载源码、配置、详细设计、CI、测试脚本、构建产物和原始运行/测试记录。项目档案只写清“当前结论是什么、为什么、关联哪个代码仓库/版本/证据”，不复制详细实现。

## 创建项目

复制 `_template/` 创建新目录，保留六份文件的编号和主职责。填写时只记录已知事实；未知项保留为待确认，不以模板文本替代实际结论。

```text
1.1-项目事实与交付档案/
  <project_id>/
    01_project_charter.md
    02_product_brief.md
    03_project_plan.md
    04_engineering_and_verification.md
    05_delivery_and_acceptance.md
    06_retrospective.md
```

项目结束后，项目档案继续保留作为交付概览和复用入口；不移动到 `Temp/`。
