# 产品简报

## 场景与问题

- 用户/使用者：内部产品、设计、前端与交付人员。
- 使用场景：评估“文字需求 -> 可运行大屏 MVP”的 Agent 协作流程，并作为后续真实项目的前端技术样例。
- 当前事实与问题证据：仅有教程文本，未提供真实用户访谈、矿山运行数据、Figma 源稿或客户验收准则。
- 问题造成的影响：只能验证技术表现与基础交互，不能据此判断业务价值或交付可用性。
- 目标结果：形成可运行的暗色 HUD 大屏、真实浙江行政区轮廓、受控图表动画和可定位代码证据。

## 边界

- 非目标：真实地形纹理、飞线/追光全套特效、后台 API、用户登录和客户部署。
- 待验证假设：真实项目是否需要浙江省地图、同类指标布局及 Three.js 交互；均待业务负责人和客户证据确认。
- 数据、接口、硬件、网络、安全或合规约束：当前使用合成数据和公开行政区边界；真实生产数据、设备网络、座舱或工控机接入必须另行完成授权、安全与性能设计。
- 产品负责人确认：待指定，不能由 Agent 替代。
