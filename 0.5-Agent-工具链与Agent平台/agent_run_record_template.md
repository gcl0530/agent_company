# Agent 运行记录模板

> 工作单元模板定义“允许 Agent 做什么”；本记录保存“某一次实际运行做了什么、依据什么事实、产生什么结果”。适用于 M1 及以上的可复用工作单元，不替代代码审查、发布审批或客户沟通记录。

## 运行身份

- 运行编号与日期：
- 工作单元与成熟度：
- 项目/需求/变更关联：
- 人类 owner 与验收人：
- 执行环境、模型/工具版本：
- 输入事实源与快照位置：
