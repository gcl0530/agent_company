# 端到端交付切片模板

## 作用

将一个可观察的用户/作业结果组织为最小可交付切片，而不是按“前端完成、后端完成、算法完成”各自宣布进度。一个切片应能从输入经过所需模块，到达可验证输出；不需要的模块可标为不适用。
