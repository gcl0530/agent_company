# 项目管理系统

## 作用

本系统将已确认的产品定义组织为可执行、可跟踪和可升级的项目。它维护责任、节奏、依赖、风险和决策，不替代产品判断、工程实现或交付验收。

## 最小流程

`立项 -> 计划与工作单元 -> 执行更新 -> 风险/决策升级 -> 交付准备 -> 复盘`

每个真实项目在 `1.1-项目事实与交付档案/<project_id>/` 维护正式计划；此目录只维护项目控制方法和模板。

## 项目质量门

- 项目目标、负责人、范围和验收已获批准。
- 每个任务有输入、输出、质量门、依赖、权限和升级路径。
- 风险、问题和决策有责任人、日期和处理状态。
- 新任务未绕开产品定义和项目计划直接进入实施。

模板见 [项目控制模板](templates/project_control_template.md)。
